# withdraw

The `withdraw` method generates, signs, and returns a transaction that transfers the `amount` of `coin` to the address indicated in the `to` argument.

This method generates a raw transaction which should then be broadcast using [send\_raw\_transaction](/komodo-defi-framework/api/legacy/send_raw_transaction/).

## Arguments

| Structure            | Type             | Description                                                                                                                                                                                                                                                                                                                                                    |
| -------------------- | ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| coin                 | string           | The name of the coin the user desires to withdraw.                                                                                                                                                                                                                                                                                                             |
| to                   | string           | Coins are withdrawn to this address.                                                                                                                                                                                                                                                                                                                           |
| amount               | string (numeric) | The amount the user desires to withdraw, ignored when `max=true`.                                                                                                                                                                                                                                                                                              |
| memo                 | string           | Optional. Adds a transaction memo for compatible coins (e.g. Tendermint ecosystem).                                                                                                                                                                                                                                                                            |
| max                  | bool             | Optional. Withdraw the maximum available amount.                                                                                                                                                                                                                                                                                                               |
| fee                  | object           | Optional. A standard [FeeInfo](/komodo-defi-framework/api/common_structures/wallet/#fee-info) object.                                                                                                                                                                                                                                                          |
| from                 | object           | HD wallets only. A standard [WithdrawFromInfo](/komodo-defi-framework/api/common_structures/wallet/#withdraw-from-info) object.                                                                                                                                                                                                                                |
| ibc\_source\_channel | integer          | Tendermint IBC transfers only. The source channel for the [IBC](https://tutorials.cosmos.network/academy/3-ibc/1-what-is-ibc.html) transaction.                                                                                                                                                                                                                |
| broadcast            | bool             | Optional, defaults to `false`. When `false`, signed transaction hex must be broadcast manually with [send\_raw\_transaction](/komodo-defi-framework/api/legacy/send_raw_transaction/). Must be set to `true` for Metamask managed transactions.                                                                                                                |
| expiration\_seconds  | integer          | Optional. Transaction expiration window in seconds. Currently only used by TRON (default 60s). Sets how long the signed transaction remains valid for broadcast.                                                                                                                                                                                               |
| fee\_method          | string           | TRON only. Optional. Selects the fee rail: `native` (default — pay the TRX bandwidth/energy fee) or `gasless` (route a TRC20 transfer through [GasFree](/komodo-defi-framework/tutorials/tron-gasfree/), paying the fee in the token). Requires a `tron_gasless_provider` configured at activation and the token opted in via its `gasless` activation config. |
| gasless              | object           | TRON only. Optional. A standard [GaslessWithdrawOptions](/komodo-defi-framework/api/common_structures/wallet/#gasless-withdraw-options) object constraining the gasless transfer (max fee, deadline, native fallback). Only valid together with `fee_method: "gasless"`.                                                                                       |

### Response

| Structure                    | Type                       | Description                                                                                                                                                                                                  |
| ---------------------------- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| from                         | array of strings           | coins are withdrawn from this address; the array contains a single element, but transactions may be sent from several addresses (UTXO coins)                                                                 |
| to                           | array of strings           | coins are withdrawn to this address; this may contain the `my_address` address, where change from UTXO coins is sent                                                                                         |
| my\_balance\_change          | string (numeric)           | the expected balance of change in `my_address` after the transaction broadcasts                                                                                                                              |
| received\_by\_me             | string (numeric)           | the amount of coins received by `my_address` after the transaction broadcasts; the value may be above zero when the transaction requires that the Komodo DeFi Framework API send change to `my_address`      |
| spent\_by\_me                | string (numeric)           | the amount of coins spent by `my_address`; this value differ from the request amount, as the transaction fee is added here                                                                                   |
| total\_amount                | string (numeric)           | the total amount of coins transferred                                                                                                                                                                        |
| fee\_details                 | object                     | the fee details of the generated transaction; this value differs for UTXO, ETH/ERC20, and TRON/TRC20 coins. See [WithdrawFee](/komodo-defi-framework/api/common_structures/wallet/#withdraw-fee) for details |
| tx\_hash                     | string                     | the hash of the generated transaction                                                                                                                                                                        |
| tx\_hex                      | string                     | transaction bytes in hexadecimal format; use this value as input for [send\_raw\_transaction](/komodo-defi-framework/api/legacy/send_raw_transaction/)                                                       |
| coin                         | string                     | the name of the coin the user wants to withdraw                                                                                                                                                              |
| kmd\_rewards                 | object (optional)          | an object containing information about accrued rewards; always exists if the coin is `KMD`                                                                                                                   |
| kmd\_rewards.amount          | string (numeric, optional) | the amount of accrued rewards                                                                                                                                                                                |
| kmd\_rewards.claimed\_by\_me | bool (optional)            | whether the rewards been claimed by me                                                                                                                                                                       |

##### Withdraw with broadcast = true

Metamask doesn't allow `eth_signTransaction` for security reasons, so we can only use `eth_sendTransaction` for processing withdrawals.
As a result, when submitting a withdrawal via metamask it will be rejected unless `"broadcast": true`.

<CodeGroup title="Withdraw" tag="POST" label="withdraw" mm2MethodDecorate="true">
  ```json
  {
    "mmrpc": "2.0",
    "userpass": "RPC_UserP@SSW0RD",
    "method": "withdraw",
  ```

#### Withdraw TRC20 token gaslessly (GasFree)

When `fee_method` is `gasless`, the TRC20 token is transferred through a [GasFree](/komodo-defi-framework/tutorials/tron-gasfree/) provider and the fee is paid in the token itself — no TRX is required. The platform coin must have been activated with a [tron\_gasless\_provider](/komodo-defi-framework/api/common_structures/activation/#tron-gasless-provider-config).

A gasless withdrawal does not produce a broadcastable `tx_hex`. Instead it returns a **signed GasFree authorization** (the `relay_type: "tron_gasfree"` payload) together with a `fee_details` object of type [`TronGasless`](/komodo-defi-framework/api/common_structures/wallet/#withdraw-fee). The `fee_details.trace_id` is `null` at this stage — the transfer has not yet been submitted.

When `max: true` is used with `fee_method: "gasless"`, KDF first preflights the GasFree transfer with a transfer value of `0`, then derives the signed authorization amount from that preflight response. Pending-transfer, unsupported-token, provider identity/address mismatch, and token-decimal mismatch states return their specific typed errors before any max amount is computed, rather than a generic zero-balance error.

### Error Responses

#### Gasless (GasFree) errors

A gasless withdrawal that cannot be served returns an error, unless `gasless.fallback_to_native: true` was set — in that case, bounded deterministic gasless-unavailable conditions fall back to a normal native (TRX-paid) transfer instead. This fallback covers no provider or missing `tron_gasless_token_config`, unsupported token, insufficient GasFree custody balance, `NotSufficientBalance`, `NotSufficientBalanceForActivation`, and `ZeroBalanceToWithdrawMax`. It does **not** cover provider identity/address or token-decimal mismatches, pending transfers, max-fee-exceeded, quote-expired, connectivity/auth/provider-upstream errors, or other non-deterministic failures.

GasFree withdraw variants such as `Unavailable`, `PendingTransfer`, `MaxFeeExceeded`, balance errors, `QuoteExpired`, `ProviderRejected`, `InvalidProviderResponse`, and `TraceNotFound` are nested under `error_type: "Gasless"` with the specific variant in `error_data`. Runtime provider errors do not all use that shape: invalid provider responses, identity/address/decimal mismatches, and provider bad requests map into `Gasless`, while auth/connectivity/upstream classes surface as top-level `Transport`, and `InvalidRequest`/`Internal`/`NotImplemented` surface as top-level `InternalError`.

| Variant                                 | HTTP status | Description                                                                                                                                   |
| --------------------------------------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Unavailable                             | 503         | Gasless is not available for this coin or request (e.g. no provider configured, or the token was not activated with `gasless.enabled: true`). |
| PendingTransfer                         | 409         | A gasless transfer is already pending for this account; wait for settlement and retry.                                                        |
| MaxFeeExceeded                          | 400         | The provider's quoted total fee (transfer fee plus any one-time activation fee) exceeds the requested `max_fee` cap.                          |
| InsufficientGasFreeBalance              | 400         | Not enough tokens in the GasFree custody address to cover amount + transfer fee. Carries `coin`, `available`, and `required` amounts.         |
| InsufficientGasFreeBalanceForActivation | 400         | As above, but the account is not yet activated, so the one-time `activation_fee` is included in `required`.                                   |
| QuoteExpired                            | 400         | The signed quote expired before submission; request a new withdrawal.                                                                         |
| ProviderRejected                        | 502         | The GasFree provider rejected the transfer.                                                                                                   |
| InvalidProviderResponse                 | 502         | The GasFree provider returned an invalid response.                                                                                            |
| TraceNotFound                           | 404         | Gasless transfer trace was not found.                                                                                                         |

An `InvalidFee` error (not nested under `Gasless`) is returned when `gasless` options are sent without `fee_method: "gasless"`, or when `deadline_seconds` is `0`.
