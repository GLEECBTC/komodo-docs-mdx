# experimental::enable\_solana\_with\_assets

Use this method to activate the Solana platform coin (SOL) together with any number of SPL tokens in a single command. Tokens can also be activated later, one at a time, with [experimental::enable\_solana\_token](/komodo-defi-framework/api/v20/coin_activation/enable_solana_token/).

<Note>
  This method is in the `experimental::` namespace, so its request and response may still change. Solana coins are currently wallet-only: they can't be used in orders or atomic swaps yet. See [Solana and SPL tokens](/komodo-defi-framework/tutorials/solana/) for the coins file entries and the Solana-specific rules around fees, rent and addresses.
</Note>

<Note>
  Solana activation supports wallets started from a seed phrase, in both Iguana and HD (`"enable_hd": true`) mode. Hardware wallets, WalletConnect and MetaMask are not supported.
</Note>

  ### Error Types

  | Structure                  | Type   | Description                                                                                                                          |
  | -------------------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------ |
  | CoinProtocolParseError     | string | Parsing the protocol of the platform coin you are trying to activate failed                                                          |
  | Internal                   | string | The request failed due to a Komodo DeFi Framework API internal error                                                                 |
  | PlatformCoinCreationError  | string | The platform coin could not be created, e.g. no nodes were given, none of them could be reached, or the wallet type is not supported |
  | PlatformConfigIsNotFound   | string | Config of the platform coin you are trying to activate is not found                                                                  |
  | PlatformIsAlreadyActivated | string | The platform coin you are trying to activate is already activated                                                                    |
  | TokenConfigIsNotFound      | string | Config of the token you are trying to activate is not found                                                                          |
  | TokenProtocolParseError    | string | Parsing the protocol of the token you are trying to activate failed                                                                  |
  | Transport                  | string | The request failed due to a network error                                                                                            |
  | UnexpectedPlatformProtocol | string | The `protocol.type` of the platform coin in the coins file is not `SOLANA`                                                           |
  | UnexpectedTokenProtocol    | string | The `protocol.type` of the token in the coins file is not `SOLANATOKEN`                                                              |
