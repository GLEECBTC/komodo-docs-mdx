# experimental::enable\_solana\_token

Use this method to activate an SPL token after its platform coin has been activated with [experimental::enable\_solana\_with\_assets](/komodo-defi-framework/api/v20/coin_activation/enable_solana_with_assets/). Tokens from both the Token and Token-2022 programs are supported.

<Note>
  This method is in the `experimental::` namespace, so its request and response may still change. See [Solana and SPL tokens](/komodo-defi-framework/tutorials/solana/) for the coins file entries.
</Note>

<Note>
  The `address` returned for a token is the wallet's address, the same as the platform coin's. It is the address to share for receiving the token: Solana wallets and exchanges send to the wallet's associated token account for the mint, which they derive from it.
</Note>

<CollapsibleSection expandedText="Hide Errors" collapsedText="Show Errors">
  ### Error Types

  | Structure                  | Type   | Description                                                                                  |
  | -------------------------- | ------ | -------------------------------------------------------------------------------------------- |
  | Internal                   | string | The request failed due to a Komodo DeFi Framework API internal error                         |
  | PlatformCoinIsNotActivated | string | The platform coin named in the token's `protocol.platform` must be activated first           |
  | TokenConfigIsNotFound      | string | Config of the token you are trying to activate is not found                                  |
  | TokenIsAlreadyActivated    | string | The token you are trying to activate is already activated                                    |
  | TokenProtocolParseError    | string | Parsing the protocol of the token you are trying to activate failed                          |
  | Transport                  | string | The request failed due to a network error, or the mint is owned by a different token program |
  | UnexpectedTokenProtocol    | string | The `protocol.type` of the token in the coins file is not `SOLANATOKEN`                      |
