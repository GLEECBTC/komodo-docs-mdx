# enable\_eth\_with\_tokens

The Komodo DeFi Framework supports ETH(Ethereum) and many other EVM type platform coins like AVAX(Avalanche), BNB(Binance), FTM(Fantom), MATIC(Polygon), ONE(Harmony), ETH-ARB20(Arbitrum), and TRX(TRON).
Additionally, it supports ERC20 tokens on the ETH chain, associated ERC20 like tokens on the rest of the EVM platform coin chains, and TRC20 tokens on TRON. Using this method, you can enable a platform coin along with multiple ERC20/TRC20 like tokens of the platform coin chain in a single command.

<Note>
  TRON (TRX) and TRC20 tokens can be activated for balance queries, withdrawals and [atomic swaps](/komodo-defi-framework/tutorials/tron-swaps/). To trade them, pass the swap contract's Base58 `T...` address as `swap_contract_address`. TRC20 tokens additionally support [gasless transfers via GasFree](/komodo-defi-framework/tutorials/tron-gasfree/) — see the `tron_gasless_provider` parameter below.
</Note>

#### Request for TRON (TRX) with gasless TRC20 transfers (GasFree)

To enable [gasless TRC20 transfers](/komodo-defi-framework/tutorials/tron-gasfree/), pass a `tron_gasless_provider` (a standard [TronGaslessProviderConfig](/komodo-defi-framework/api/common_structures/activation/#tron-gasless-provider-config)) when activating the TRON platform coin, and on each TRC20 [TokensRequest](/komodo-defi-framework/api/common_structures/activation/#tokens-request) a per-token `gasless` object with `enabled: true` (plus an optional `transfer_max_fee` cap) to opt that token into gasless transfers. Once activated, the response includes each address's `gasfree_address`, and gasless withdrawals become available through the [withdraw](/komodo-defi-framework/api/v20/wallet/tx/withdraw/) `fee_method: "gasless"` option.

<Note>
  Set `service` to `"komodo_proxy"` to route requests through the Komodo proxy instead of supplying your own GasFree API credentials. See [TronGaslessProviderConfig](/komodo-defi-framework/api/common_structures/activation/#tron-gasless-provider-config).
</Note>

### Error Responses

<CollapsibleSection expandedText="Hide Errors" collapsedText="Show Errors">
  ### Error Types

  | Structure                  | Type   | Description                                                                         |
  | -------------------------- | ------ | ----------------------------------------------------------------------------------- |
  | CoinProtocolParseError     | string | Parsing the protocol of the platform coin you are trying to activate failed         |
  | InternalError              | string | The request was failed due to an Komodo DeFi Framework API internal error           |
  | PlatformCoinCreationError  | string | There was an error when trying to activate the platform coin                        |
  | PlatformConfigIsNotFound   | string | Config of the platform coin you are trying to activate is not found                 |
  | PlatformIsAlreadyActivated | string | The platform coin you are trying to activate is already activated                   |
  | PrivKeyNotAllowed          | string | The privkey is not allowed                                                          |
  | TokenConfigIsNotFound      | string | Config of the token you are trying to activate is not found                         |
  | TokenProtocolParseError    | string | Parsing the protocol of the token you are trying to activate failed                 |
  | Transport                  | string | The request was failed due to a network error                                       |
  | UnexpectedDerivationMethod | string | The derivation method used is unexpected                                            |
  | UnexpectedPlatformProtocol | string | Unexpected platform protocol found for the platform coin you are trying to activate |
  | UnexpectedTokenProtocol    | string | Unexpected protocol is found in the config of the token you are trying to activate  |
